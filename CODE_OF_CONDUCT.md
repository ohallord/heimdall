# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussion focused on the work. Harassment, personal attacks and discriminatory language are not acceptable in any project space: issues, pull requests, discussions, or any other channel connected to the project.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainers privately at **CONDUCT_CONTACT_EMAIL**. Reports are handled confidentially. The maintainers will review each report and respond with the actions described in the Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, or permanent ban).
